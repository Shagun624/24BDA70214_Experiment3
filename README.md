## 3. Defined Approach

In this experiment, I created a React.js application with three main modules:

### 🔹 Experiment 3.1 - Product Cart System
- Displayed a list of products with image, price, and stock status
- Added "Add to Cart" feature
- Implemented remove item from cart
- Calculated total bill dynamically

### 🔹 Experiment 3.2 - Library Management System
- Added books with title and author
- Implemented search functionality
- Displayed list of books dynamically
- Added remove book feature
- Showed message when no books are available

### 🔹 Experiment 3.3 - Person Class Hierarchy (OOP Concept)
- Created base class Person
- Extended classes Student and Teacher
- Took input from user (name, age, role, extra details)
- Displayed object details using inheritance
